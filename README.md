# Bouncelike

# Plot:
  

Jeff the wizard's evil twin (creatively named evil jeff) are fighting to the death... Jeff uses magic attacks (he watched one touhou video and was inspired) and shoots really cool attacks. Get evil jeff to 0 health (from 40,000) without dying and you get nothing!

# Control:
WASD to move
L to shoot and k to show hitboxes ( DO NOT DO THIS ON WEB IT WILL LAG)
